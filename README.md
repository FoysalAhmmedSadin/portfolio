## SEO & Search Visibility

The project includes search-engine metadata and crawler-related files such as:

- Page title and meta description
- Open Graph and social sharing metadata
- Person structured data (JSON-LD)
- `robots.txt`
- `sitemap.xml`

Each public deployment should use its own correct canonical URL if it is intended to be indexed independently. Search engines decide which pages to show; separate indexing or ranking of all three addresses is not guaranteed, especially when their content is identical. Distinct, useful content for each site can help clarify its purpose.

After deployment, verify each domain in [Google Search Console](https://search.google.com/search-console/about), submit its sitemap, and use URL Inspection to check indexing status.
